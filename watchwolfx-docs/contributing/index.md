# Contributing

WatchWolfX is a Gradle-based Java monorepo with Docker-backed integration paths.

- [Development](development.md) covers module builds, tests, documentation previews, and repository hygiene.
- [Releases](releases.md) documents version validation, published artifacts, image tags, and the release checklist.

Changes should remain scoped to the module that owns the behavior and preserve protocol compatibility unless a
breaking change is intentional and documented.
